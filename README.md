# Cab — سامانه حمل و نقل تهران

## پروژه کامل MVP

### ساختار پروژه
```
cab/
├── apps/server/        # بک‌اند Node.js + Express + Prisma + SQLite + Socket.IO
├── apps/mobile/        # اپلیکیشن Expo + React Native + TypeScript
└── .gitignore
```

## دستورات اجرا

### ۱. بک‌اند
```bash
cd apps/server
cp .env.example .env       # کلیدهای نشان از داخل فایل .env اصلی کپی شدند
npm install
npx prisma db push         # ساخت دیتابیس SQLite
npx tsx prisma/seed.ts     # کاربر آزمایشی (اختیاری)
npm run dev                # اجرا روی http://localhost:3000
```

### ۲. اپ موبایل
```bash
cd apps/mobile
cp .env.example .env       # تنظیم آدرس بک‌اند
# برای شبیه‌ساز آیفون:
# EXPO_PUBLIC_API_URL=http://localhost:3000/api
# EXPO_PUBLIC_SOCKET_URL=http://localhost:3000
# برای آیفون فیزیکی (IP سیستم را جایگزین کنید):
# EXPO_PUBLIC_API_URL=http://192.168.1.x:3000/api
# EXPO_PUBLIC_SOCKET_URL=http://192.168.1.x:3000

npm install
npx expo run:ios           # نیاز به Development Build
```

## قابلیت‌های تکمیل‌شده

### بک‌اند (کامل)
- ثبت‌نام و ورود با شماره موبایل + OTP آزمایشی 123456
- JWT احراز هویت، ذخیره امن توکن
- دو نقش مجزا: مسافر و سفیر
- وضعیت سفیر: آنلاین/آفلاین، فعال/غیرفعال دریافت سفر
- مدل سفر با ۹ وضعیت (SEARCHING تا COMPLETED)
- تخصیص نزدیک‌ترین سفیر واجد شرایط با مهلت ۱۵ ثانیه
- محاسبه قیمت: مبلغ پایه + نرخ کیلومتر + نرخ دقیقه
- مسیریابی واقعی با Neshan Direction API (v4)
- Reverse Geocoding با Neshan v5
- جستجوی آدرس با Neshan v4 Geocoding
- Socket.IO: موقعیت زنده سفیر، پیشنهاد سفر، تغییر وضعیت
- کنترل تغییر وضعیت سفر (مسیرهای مجاز)
- Prevenir تخصیص هم‌زمان
- Seed داده نمونه

### اپ موبایل (تکمیل‌شده)
- **صفحه انتخاب نقش**: مسافر / سفیر
- **صفحه ورود**: پوستر خودرو + شماره موبایل + OTP (فونت وزیرمتن به‌صورت لوکال)
- **صفحه تأیید کد**: OTP و ثبت‌نام
- **انتخاب مسیر**: نقشه نشان (Leaflet داخل WebView، بارگذاری یک‌باره بدون ری‌استارت)، نشانگر ثابت مرکزی، جستجوی آدرس، تأیید صریح مبدأ/مقصد، GPS با وضعیت «در حال دریافت موقعیت»
- **کرایه**: مسافت، زمان و قیمت واقعی از مسیریابی نشان پیش از ثبت درخواست
- **سفر فعال مسافر**: وضعیت‌های واقعی ارسال از سرور، اطلاعات سفیر پس از پذیرش، موقعیت زنده، لغو
- **پنل سفیر**: نقشه، آنلاین/آفلاین، فعال/غیرفعال دریافت سفر، کارت درخواست (۱۵ ثانیه)، پذیرش/رد، در مسیر مبدأ → رسیدم → شروع سفر → پایان سفر
- **پشتیبانی وب**: `npx expo export --platform web` بدون خطا؛ فونت وزیرمتن لوکال؛ طراحی روشن و RTL

### نکات فنی نسخه فعلی
- نقشه با `react-native-webview` + Leaflet و تایل نشان پیاده شده؛ HTML نقشه فقط یک‌بار ساخته می‌شود و نشانگرها/مسیر/انیمیشن دوربین از طریق postMessage اعمال می‌شوند (بدون ری‌لود نقشه).
- پس از تأیید OTP، مسیر مقصد بر اساس نقش واقعی ذخیره‌شده در سرور انتخاب می‌شود (`/(passenger)` یا `/(driver)`).
- وضعیت سفر فقط از رویدادهای واقعی سرور (Socket.IO + API) خوانده می‌شود؛ پیام «سفیری در دسترس نیست» تنها پس از `NO_DRIVER_AVAILABLE` از سرور نمایش داده می‌شود.

### تنظیمات API نشان
| متغیر | محل | سرویس |
|---|---|---|
| `NESHAN_SERVICE_API_KEY` | server/.env | مسیریابی، معکوس، جستجو |
| `NESHAN_TILE_API_KEY` | server/.env | تایل نقشه |
| `NESHAN_WEB_MAP_API_KEY` | server/.env | نقشه وب |

کلید خصوصی مسیریابی فقط روی سرور ذخیره می‌شود.

### محدودیت‌های باقی‌مانده
1. **اپلیکیشن نیاز به Development Build دارد** (`npx expo run:ios`). Expo Go کافی نیست.
2. **نقشه از react-native-maps (Apple Maps) استفاده می‌کند**، نه MapLibre. دلیل: `@maplibre/maplibre-react-native` با نسخه Expo 52 ناسازگاری داشت. در صورت نیاز به تایل نشان، MapLibre را با نسخه مناسب Expo تنظیم کنید.
3. **مسیریابی Neshan با کلید test کار می‌کند** اما ممکن است محدودیت نرخ داشته باشد.
4. **برای آیفون فیزیکی** باید آدرس بک‌اند را به IP شبکه محلی تغییر دهید.
5. **SMS واقعی نیست** — صرفاً OTP آزمایشی 123456 در محیط توسعه.
